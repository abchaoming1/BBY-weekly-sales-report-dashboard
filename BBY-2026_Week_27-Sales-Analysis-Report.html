📊 业务线表现深度分析 (Week 27)

核心结论：本周总销量为10,012条，环比+6.85%，同比-32.32%；销售额为$1,842,230，环比+7.61%，同比-25.17%。线上销量2,505条，线上占比25.02%，较上周-0.45pct；POP单店单周8.87，环比+0.57。整体来看，本周以回升为主，增量主要来自重点促销SKU放量与线上渠道回暖。

分业务线表现：骨导线本周5,258条，占比52.52%，环比+3.42%，弱于大盘；其中S820 / S821系列合计3,331条，环比-0.51%，仍是体量最大的核心系列。气导线本周4,754条，占比47.48%，环比+10.92%，强于大盘。说明本周表现并非平均扩散，而是由重点系列带动。

耳夹 / 耳挂拆分：耳夹线(E310 / E320 / E210)合计2,002条，环比+18.39%，整体增长；耳挂线(T010 / T511 / T920 / T921 / T910)合计2,752条，环比+6.05%，整体增长。其中E310在促销带动下由478条升至711条，但E320 / E210合计由1,213条升至1,291条，环比+6.43%，说明耳夹线已经出现净新增扩容。

关键SKU动态：S820 / S821系列本周3,331条，促销条件为无明显促销支持，仍是本周最核心的销量支柱。T921本周744条，环比-3.63%，在1天、促销价$149.99、折扣20%支持下明显回落。E310本周711条，环比+48.74%，在无明显促销支持推动下延续回升，线上销量由121条升至365条。T010本周无折扣，销量1,256条，环比+20.89%，自然需求仍在，但阶段性被促销SKU分流。S803虽有无明显促销支持，但销量降至865条，环比+19.15%，出现回升，促销效率明显弱于S820 / T921。

经营判断：本周大盘回升更多来自促销与线上曝光修复，新品自然拉动仍需继续验证。后续需要重点观察S820 / T921促销结束后的留量能力，以及E320 / E210能否摆脱对E310的内部替代。
