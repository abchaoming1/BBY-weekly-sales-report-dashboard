📊 业务线表现深度分析 (Week 30)

核心结论：本周总销量为10,089条，环比-17.24%，同比-1.56%；销售额为$1,843,151，环比-15.33%，同比+9.49%。线上销量2,312条，线上占比22.92%，较上周-6.21pct；POP单店单周9.22，环比-0.96。整体来看，本周以回落为主，压力主要来自促销回落与线上需求转弱。

分业务线表现：骨导线本周5,624条，占比55.74%，环比-19.67%，弱于大盘；其中S820 / S821系列合计3,702条，环比-17.09%，仍是体量最大的核心系列。气导线本周4,465条，占比44.26%，环比-13.95%，强于大盘。说明本周整体仍在回调阶段，但气导线相对更稳。

耳夹 / 耳挂拆分：耳夹线(E310 / E320 / E210)合计1,695条，环比-5.99%，整体下滑；耳挂线(T010 / T511 / T920 / T921 / T910)合计2,770条，环比-18.19%，整体下滑。其中E310由520条降至386条，但E320 / E210合计由1,283条升至1,309条，环比+2.03%，说明新品当前更多是在耳夹内部重新分配需求，尚未形成明显净新增。

关键SKU动态：S820 / S821系列本周3,702条，促销条件为1天、促销价$139.99、折扣22%，仍是本周最核心的销量支柱。T921本周782条，环比-29.68%，在1天、促销价$159.99、折扣20%支持下明显回落。E310本周386条，环比-25.77%，促销状态为1天、促销价$149.99、折扣20%，明显回落，线上销量由233条降至165条。T010本周无折扣，销量1,133条，环比-0.35%，自然需求仍在，但阶段性被促销SKU分流。S803本周无明显促销支持，销量为843条，环比-35.60%，继续回落，对整体增量的拉动仍弱于S820 / T921。

经营判断：本周大盘回落更多来自促销缩短与线上热度回落，新品仍未形成独立净新增。后续需要重点观察S820 / T921促销结束后的留量能力，以及E320 / E210能否摆脱对E310的内部替代。
